# 🔐 Password Strength Checker

## 📌 Project Overview

This project is part of **Week 1** of my **DecodeLabs Cyber Security Internship (Batch 2026)**.

It is a Python application that helps users understand how secure their passwords are. It examines different password characteristics, calculates a strength score, and displays a result such as Weak, Medium, or Strong. It also gives feedback on how a password can be improved.

---

## ✨ Features

- Checks whether a password meets the required length.
- Finds uppercase and lowercase letters.
- Detects numbers and special symbols.
- Calculates a password security score.
- Displays the password strength level.
- Gives recommendations for improving password security.
- Includes unit tests to check the program's functionality.

---

## 🛠️ Technologies Used

- **Python 3** – For developing the application.
- **Regular Expressions (re)** – For identifying password character patterns.
- **Visual Studio Code** – For writing and running the code.
- **Python unittest** – For testing the application.
